# 橘屋 x 養雞場 (純切版）| 2022.01
![](https://i.imgur.com/5tva0po.jpg)

## 專案說明
以養雞場為主題的 **單頁式** 形象網站。


## 開發目的
- 練習 SASS/SCSS 、RWD 以及 jQuery 的使用
- 練習 套件應用 (輪播圖、燈箱效果)


## Demo
- https://jhihying.github.io/eggfarm/


## 使用技術 / 套件
| 類別        | 技術／工具說明                                   |
|------------|------------------------------------------------|
| 技術        | HTML5、CSS3、SASS (SCSS)、jQuery、RWD      |
| 套件應用     | Swiper (輪播圖)、AOS (視覺滾差動畫)、Lightbox 2 (燈箱)  |
| 部署平台     | GitHub Pages                                      |
